# AGENTS.md — Bank of America Mobile Banking iOS

## Commands

| Task | Command |
|---|---|
| Regenerate Xcode project (after adding/moving files) | `xcodegen generate` |
| Build (no backend) | `xcodebuild -project BofAMobile.xcodeproj -scheme BofAMobile-Mock -destination 'platform=iOS Simulator,name=iPhone 17' build` |
| Unit tests (app) | `xcodebuild test -project BofAMobile.xcodeproj -scheme BofAMobile-Mock -destination 'platform=iOS Simulator,name=iPhone 17'` |
| Unit tests (BoAFoundation) | `cd Packages/BoAFoundation && xcodebuild test -scheme BoAFoundation -destination 'platform=iOS Simulator,name=iPhone 17'` |
| Full CI run | `scripts/ci-build.sh` |
| Run in Simulator (Mock) | `scripts/run-simulator.sh` |
| Run against local services | Start core-banking (:8080) and payments hub (:8081), then run scheme `BofAMobile` |

Mock sign-in: `dana.whitfield` / `Welcome1!`. Mock bundle ID: `com.bofa.mobile.mock`.

## Conventions

- Swift 5 language mode, iOS 15 deployment target. Do not raise either without a ticket.
- New screens: SwiftUI hosted in `UIHostingController`. Existing UIKit screens stay UIKit unless the ticket
  is a migration. UIKit layout uses SnapKit; no storyboards except `LaunchScreen`.
- Networking goes through `APIClient` + an `Endpoint` factory in `Networking/Endpoint.swift`. Endpoints,
  field names and error codes must match the platform API contract (`docs/API.md` in the core platform repo).
- Amounts are `Money` (never `Double`); account numbers are shown masked via `AccountNumbers.mask`.
- Shared money/date/account helpers live in `Packages/BoAFoundation` and mirror `boa-common`. Keep behaviour
  identical to the Java implementation.
- Every new endpoint needs a mock handler in `Mock/MockBackend.swift` so the Mock scheme keeps working.
- Tests: XCTest in `BofAMobileTests/` (app) and `Packages/BoAFoundation/Tests/`. Name tests
  `test<Behaviour>`.
- `BofAMobile.xcodeproj` is generated by XcodeGen from `project.yml`; edit `project.yml`, then
  regenerate and commit both.
- Commit messages: imperative subject, ticket key first when there is one (`MOB-1234: ...`).
